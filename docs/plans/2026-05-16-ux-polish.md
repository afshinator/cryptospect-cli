## Design Decisions Made This Session

- **Version format**: `v1.0.0` (v-prefix, 3-part SemVer), matching metric provider convention
- **No git tag yet**: Tag `v1.0.0` at actual release time. Source default is hardcoded `"v1.0.0"`.
- **Cache docs**: Full detail in README (~15-20 lines)
- **Pretty-print**: Wired via existing `output.pretty` config field (no new CLI flag). Users set `output.pretty: true` in `~/.cryptospect.yaml`.

## Implementation Plan

### Phase 1: Binary Rebuild + Version Fix

**File: `internal/version/version.go`** (new — ~40 lines)

Create a version package:
- Default: `"v1.0.0"` (hardcoded, bumped manually per release)
- `runtime/debug.ReadBuildInfo()` extracts VCS commit hash + dirty flag automatically
- `String()` returns clean version; `Full()` adds OS/arch/commit context
- Production builds: ldflags override `Value` with git tag
- Dev builds (`go build`): shows `v1.0.0 (79661f1-dirty)` — always identifiable

**File: `cmd/cryptospect-cli/main.go`**

Remove `var version = "dev"`. Import `internal/version` instead.

**File: `cmd/cryptospect-cli/root.go`**

Change `Version: version` → `Version: version.String()`.

**File: `Makefile`**

Remove `--always` from `git describe` (no more raw commit hashes as version). When no tag exists, falls back to empty → ldflags won't override → source default `v1.0.0` used.

```makefile
VERSION := $(shell git describe --tags --dirty 2>/dev/null || echo "")
LDFLAGS := -s -w -X github.com/afshinator/cryptospect-cli/internal/version.Value=$(VERSION)
```

### Phase 2: Flag & Command UX Fixes

**File: `cmd/cryptospect-cli/root.go`**

| Change | New Value |
|--------|-----------|
| `--api-key` description | `"API key for CoinGecko authenticated endpoints. All metrics work without a key; a key unlocks Pro-tier rate limits and derivatives data."` |
| `-o/--output` description | `"Output format. Currently only \"json\" is supported (forward-compatibility placeholder)."` |
| Completion hiding | `cmd.CompletionOptions = cobra.CompletionOptions{HiddenDefaultCmd: true}` |

**File: `cmd/cryptospect-cli/cache.go`**

Add `Long` description explaining:
- Where cache lives (`~/.cryptospect-cli/cache/`)
- What it stores (API responses keyed by endpoint)
- When to use (force fresh data, troubleshoot stale results, clear before API changes)
- Cache is shared across metrics and auto-repopulated

### Phase 3: Pretty-Print Support

**File: `internal/output/writer.go`**

Add package-level `pretty` bool + `SetPretty(bool)`. When true, use `json.MarshalIndent` with 2-space indent.

**File: `cmd/cryptospect-cli/root.go`** (in `PersistentPreRunE`)

The config template in `config.go:Write()` already documents `pretty: false`.
